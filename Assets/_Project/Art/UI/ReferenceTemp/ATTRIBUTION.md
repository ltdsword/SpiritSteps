# Prototype Reference Assets

This folder contains a deliberately small subset of the supplied Pikmin Bloom sprite dump and the supplied Vietnamese Memory Explorer reference art. These files are isolated for a non-commercial prototype and must not be treated as production-owned art.

## Included only for prototype validation

- Navigation and utility icons: AR, camera, compass, current location, steps, seedling, lifelog, calendar, place, star, settings, back, close, and help.
- Six seedling stage images: sprout and ready variants for red, blue, and yellow.
- Three spirit images, one memory-fragment image, four landmark images, and three scene/journal images from the direct project reference.

No mushroom or battle-related image has been imported.
